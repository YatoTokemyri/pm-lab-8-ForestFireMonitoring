# Инструкция по загрузке данных

Данный ноутбук собирает пространственные данные из OpenStreetMap (леса, камеры, границы районов) для выбранной территории.

## Как повторить загрузку данных

1. Откройте ноутбук `notebooks/01_data_collection.ipynb` в Google Colab (через меню "Файл" -> "Открыть блокнот" -> вкладка GitHub).
2. В первой ячейке кода (в блоке `# === Параметры вашего варианта ===`) убедитесь, что указана нужная территория в переменной `PLACE` (по умолчанию: "Уфа, Республика Башкортостан, Россия").
3. В ячейке настройки среды (где написано `PROJECT_FOLDER = ...`) впишите точное имя вашей папки на Google Диске. Убедитесь, что у вас есть к ней доступ.
4. В верхнем меню выберите **Среда выполнения → Выполнить все** (Runtime → Run all).
5. Когда Colab запросит доступ к Google Диску, выберите свой аккаунт и разрешите доступ.
6. Дождитесь окончания загрузки. Все файлы (boundary, districts, forests, cameras) сохранятся в папку `data/raw` на вашем Google Диске.

## Возможные проблемы и их решение

* **Ошибка 502 (Bad Gateway)**: Публичный сервер OpenStreetMap (Overpass API) часто перегружен. Если вы видите эту ошибку, подождите 5–10 минут и запустите ячейку загрузки слоев снова. Уже скачанные данные сохраняются в кэш и не будут загружаться повторно.
* **Файлы не появляются на Диске**: Проверьте правильность написания имени папки в переменной `PROJECT_FOLDER`. Оно должно совпадать с названием папки в «Моём диске» (через ярлык Colab её не увидит).

## Примечание
В рамках тестирования данные были успешно собраны для города Уфы (7 районов, 2582 лесных полигона, 13 камер). Для полного покрытия республики можно добавить другие крупные города в список `PLACES_TO_LOAD`.
