# Оценка трудоёмкости

## 1. Оценка историй (Planning Poker)
**Статус.** Рабочие оценки для подготовки командной сессии. Владелец продукта подтверждает состав историй и критерии приёмки. После голосования здесь фиксируются согласованные SP, а в `Estimate` на доске вносятся те же значения.

Эталонная история: US-5 «Открыть панель по ссылке» = 3 SP. Почему выбрана: история даёт проверяемый результат: второй участник открывает готовую панель с другого компьютера по ссылке из README. Состав панели покрывают отдельные истории. Публикация и проверка по ссылке позволяют сравнить другие работы с понятным объёмом.

Шкала — 1, 2, 3, 5, 8, 13, 21 и «?». История на 13 SP или больше делится на истории с самостоятельным результатом, затем каждая оценивается отдельно.

**Итого MVP — 32 SP**, из них 29 SP Must и 3 SP Should.

Исходная US-1 разделена на получение спутниковых аномалий и подготовку геослоёв. Исходная US-3 разделена на просмотр карты и ручную верификацию. В сумму входят оценки получившихся частей. US-4 «Отчёт по слепым зонам и пожарам» относится к следующим версиям согласно [карте историй](requirements.md#карта-историй-и-mvp).
