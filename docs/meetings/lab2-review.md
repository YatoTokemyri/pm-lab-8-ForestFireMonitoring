## Обсуждённые ограничения

- Загруженные городские слои относятся к Уфе; результаты по ним нельзя распространять на всю Республику Башкортостан.
- Найденные в OSM объекты видеонаблюдения не подтверждают расположение и покрытие камер «Лесохранитель».
- Исторические данные о пожарах и проверенная загрузка спутниковых аномалий пока не представлены.
- Поэтому достоверность расчёта слепых зон и осуществимость исходного MVP требуют дополнительной проверки.

## Предлагаемые решения для согласования на обзоре

1. Использовать Уфу как пилотную территорию первичного анализа. Решение о территории итогового продукта принять после проверки данных.
2. Сохранить текущий состав MVP в требованиях. Если нужные источники окажутся недоступны, отдельно согласовать изменение MVP.
3. Показывать расчёт по объектам OSM как предварительный сценарий с указанными допущениями, а не как фактическое покрытие пожарных камер.
4. Продолжить поиск подтверждённого перечня камер, истории пожаров и спутниковых данных.
