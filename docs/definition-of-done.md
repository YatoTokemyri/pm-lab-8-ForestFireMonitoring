## Definition of Ready (задача готова к работе)

Задачу можно брать в спринт, если:
- [ ] У задачи есть понятная цель и критерии приёмки («Готово, когда»)
- [ ] Задача привязана к эпику (E1–E6) и к этапу (Milestone), у истории указан приоритет MoSCoW
- [ ] Указаны связанные требования (FR, NFR, DR) или пакет WBS
- [ ] Известно, какие данные нужны и где они лежат (для задач с данными и расчётами)
- [ ] Зависимости сняты или известна дата, когда они будут сняты
- [ ] Команда считает, что задача помещается в один спринт (2 недели); числовая оценка появится в ЛР 3

## Definition of Done (задача выполнена)

### Для любой задачи
- [ ] Выполнены все критерии приёмки из задачи
- [ ] Изменения влиты в `main` через Pull Request с `Closes #N`
- [ ] Pull Request одобрил другой участник команды (минимум 1 аппрув)
- [ ] Автопроверки в Pull Request прошли без ошибок
- [ ] В документах нет пустых разделов, пометок TODO и шаблонных полей `<...>`
- [ ] Для фактов и цифр указаны источники
- [ ] Документация обновлена, если изменилось поведение или структура проекта
- [ ] ИИ-ассистент, если использовался, записан в `docs/ai-usage.md` 

### Для задач с данными
- [ ] Источник, лицензия и дата загрузки записаны в `data/sources.md`
- [ ] Сырые данные не попали в Git (`data/raw/` содержит только `.gitkeep`)
- [ ] Файлы в `data/processed/` не больше 10 МБ
- [ ] Площади и расстояния посчитаны в метрической системе координат, а не в EPSG:4326
- [ ] Ноутбук запускается сверху вниз без ошибок и сохранён без вывода ячеек
- [ ] Загрузку повторил другой участник по инструкции из `data/README.md`
- [ ] Задержка спутниковых данных проверена и не превышает 24 часа (DR-03)

### Для пользовательских историй
- [ ] Каждый сценарий критериев приёмки проверен и пройден
- [ ] Выполнены связанные нефункциональные требования (NFR), которые указаны в истории
- [ ] На карте есть подпись источника данных (DR-04) и легенда
- [ ] Результат показан владельцу продукта, замечания заведены задачами
