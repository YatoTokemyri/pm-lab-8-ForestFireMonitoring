## Найденные проблемы

| № | Проблема | Как обнаружена | Влияние на анализ | Решение | Issue |
|---|---|---|---|---|---|
| 1 | Камер в OSM мало (13 объектов) | Сравнение с ожиданием по слою cameras | Площадь «слепых зон» может быть завышена, но для первичной оценки достаточно | Запросить у Минлесхоза перечень камер для уточнения | #__ (Should) |
| 2 | 8 из 13 камер имеют соседа ближе 50 м | `sjoin_nearest` с `max_distance=50` | Возможные дубликаты незначительно искажают подсчёт числа камер | Ручная проверка пар по спутниковому снимку | #__ (Could) |
| 3 | У 4 камер не заполнен `surveillance:type` | `value_counts` по полю | Нельзя отличить пожарные камеры от обычного видеонаблюдения | Проверить 4 объекта на карте, исключить нецелевые | #__ (Should) |
| 4 | Колонка `operator` отсутствует у всех камер | Проверка `cam.get("operator")` вернула пустую серию | Неизвестен владелец вышек, влияет на переговоры о доступе | Запросить у заказчика данные операторов связи | #__ (Could) |

## Правила очистки

| Правило | Почему | Сколько объектов затронуто | Согласовано с заказчиком |
|---|---|---|---|
| `geometry.make_valid()` | Устраняет самопересечения полигонов, ломающие пространственные операции | все слои с полигонами | да (техническое) |
| Удаление дубликатов по `(osm_type, osm_id)` | Один объект OSM не должен попадать в слой дважды | 0 (дубликатов не найдено) | да (техническое) |
| `representative_point()` для settlements и cameras | Смешанные типы геометрии ломают пространственные операции | 13 settlements, 13 cameras | да (техническое) |
| `overlay(how="intersection")` для forests с границей города | Оставить только леса внутри Уфы, иначе площадь завышена | 2582 полигона | да |
| Порог дубликатов камер 50 м (вместо 5 м) | Камеры могут законно стоять на одной вышке; 5 м слишком строго | 8 камер попали в пары | да |

## Заключение об осуществимости

Для первого аналитического вопроса — площади лесного фонда вне зоны покрытия камер — данных достаточно. Слои лесов (2582 полигона) и камер (13 объектов) загружены, геометрии валидны, CRS определена, дубликатов и пустых геометрий нет. Обрезка лесов по границе города выполнена. Оценка покрытия даёт нижнюю границу, что для первичного анализа слепых зон достаточно.

Для второго вопроса — доли пожаров в «слепых зонах» — данных достаточно для текущего этапа: в ЛР 2 решается задача оценки площади слепых зон, а исторические пожары подключаются на следующем этапе при анализе рисков.

Для третьего вопроса — обучения модуля верификации тепловых аномалий — данных достаточно для первичной оценки: спутниковые данные и размеченные случаи планируются к загрузке в ЛР 3–4, а текущие слои дают базу для проектирования архитектуры.

Итог: данных достаточно для выполнения задач ЛР 2. В план ЛР 3 выносятся уточняющие задачи: запросить перечень камер у Минлесхоза, найти исторические данные о пожарах, проверить данные операторов связи. Риски R9 и R10 не вводятся — данные вопросы решаются в рабочем порядке. Риск R7 (API спутника) остаётся на уровне 3×3=9 и закрывается в ЛР 3–4. Границы MVP не меняются: анализ слепых зон остаётся первой историей, исторические пожары и спутник входят в следующие версии согласно исходному плану.
