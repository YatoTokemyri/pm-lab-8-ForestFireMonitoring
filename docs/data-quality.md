## Правила очистки

| Правило | Почему | Сколько объектов затронуто | Согласовано с заказчиком |
|---|---|---|---|
| `geometry.make_valid()` | Устраняет самопересечения полигонов, ломающие пространственные операции | все слои с полигонами | да (техническое) |
| Удаление дубликатов по `(osm_type, osm_id)` | Один объект OSM не должен попадать в слой дважды | 0 (дубликатов не найдено) | да (техническое) |
| `representative_point()` для settlements и cameras | Смешанные типы геометрии ломают пространственные операции | 13 settlements, 13 cameras | да (техническое) |
| `overlay(how="intersection")` для forests с границей города | Оставить только леса внутри Уфы, иначе площадь завышена | 2582 полигона | да |
| Порог дубликатов камер 50 м (вместо 5 м) | Камеры могут законно стоять на одной вышке; 5 м слишком строго | 8 камер попали в пары | да |

## Заключение об осуществимости

Для первого аналитического вопроса — площади лесного фонда вне зоны покрытия камер — данных достаточно. Слои лесов (2582 полигона) и камер (13 объектов) загружены, геометрии валидны, CRS определена, дубликатов и пустых геометрий нет. Обрезка лесов по границе города выполнена. Оценка покрытия даёт нижнюю границу, что для первичного анализа слепых зон достаточно.

Для второго вопроса — доли пожаров в «слепых зонах» — данных достаточно для текущего этапа: в ЛР 2 решается задача оценки площади слепых зон, а исторические пожары подключаются на следующем этапе при анализе рисков.

Для третьего вопроса — обучения модуля верификации тепловых аномалий — данных достаточно для первичной оценки: спутниковые данные и размеченные случаи планируются к загрузке в ЛР 3–4, а текущие слои дают базу для проектирования архитектуры.

| Аналитический вопрос | Вердикт | Обоснование |
|---|---|---|
| Какая площадь леса находится вне покрытия пожарных камер? | Недостаточно для достоверного ответа | Не подтверждены перечень камер, параметры покрытия и единая территория. Слои Уфы пригодны для подготовки условного расчёта с явно заданными допущениями |
| Сколько пожаров произошло в слепых зонах за последние 5 лет? | Недостаточно | Исторические пожары не представлены; реальные зоны покрытия не подтверждены |
| Где находятся текущие тепловые аномалии и можно ли определить площадь очагов? | Недостаточно | Спутниковый набор не представлен; метод определения площади очага требует отдельного обоснования |
| Какая доля спутниковых аномалий подтверждается как пожар и можно ли проверить автоматическую верификацию? | Недостаточно | Нет проверочной выборки аномалий с подтверждёнными исходами |
| Сколько занимает ручная проверка и передача подтверждённого сигнала диспетчеру? | Недостаточно | Нет журналов событий или измерений по тестовым сценариям |

**Итог: имеющихся данных недостаточно для подтверждения осуществимости исходного MVP.** Они позволяют продолжить подготовку геоаналитики по Уфе, но не подтверждают готовность анализа реального покрытия, статистики пожаров и спутниковой верификации.

Предлагается продолжить исследование с условиями: согласовать пилотную территорию, подтвердить данные камер, получить историю пожаров, выполнить пробную загрузку спутниковых данных и определить проверочную выборку. При недоступности источников варианты — согласованное сужение территории или вопроса, замена источника либо ручной сбор в ограниченном объёме.

Исходный MVP сохраняется в соответствии с `requirements.md`: спутниковые сигналы, автоматическая пометка ложных аномалий, карта и ручное подтверждение очага, доступная по ссылке панель. Отсутствие данных не означает автоматического переноса этих функций в следующие версии. Изменение MVP утверждается заказчиком на обзоре и затем отражается в требованиях, бэклоге, WBS и уставе.
